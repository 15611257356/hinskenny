# HinsKenny 内容工作台

这是一个只在本机运行的内容维护模块，用于统一管理人物、时间线、糖点、相册、音乐、来源和图片版权。

公开网站仍然是纯静态页面。工作台的本地服务负责保存 JSON、上传图片、检查内容，并在确认发布后生成根目录的 `data.js` 与 `credits.js`。

## 启动

在项目根目录运行：

```bash
python3 studio/server.py
```

然后打开：

```text
http://127.0.0.1:8765/studio/
```

服务只监听 `127.0.0.1`，局域网和互联网无法直接访问。

## 推荐维护流程

1. 点击对应板块，再选择或新增一行。
2. 在右侧子标签填写基本信息、正文、媒体和出处。
3. 点击“保存草稿”。这一步只更新 `studio/content/*.json`。
4. 点击“检查内容”，修复错误并处理重要提醒。
5. 点击“预览主站”，查看包含草稿的临时页面。
6. 确认后点击“发布到主站”。

发布时：

- 只把“已发布”状态的条目写入主站。
- 草稿和归档内容继续保留在工作台数据中。
- 原有 `data.js` 与 `credits.js` 会备份到 `studio/backups/`。
- Git 仍然是最终的审查和回滚机制。

## 文件结构

```text
studio/
├── index.html             # 工作台页面骨架
├── studio.css             # 工作台布局与样式
├── schemas.js             # 各板块的字段模板
├── studio.js              # 列表、表单、保存、预览和发布交互
├── server.py              # 本地静态服务与内容 API
├── content/
│   ├── site.json          # 站点内容的唯一编辑源
│   └── credits.json       # 图片版权的唯一编辑源
└── backups/               # 发布时自动生成，不需要手工维护
```

## 图片上传

在照片字段旁点击“上传图片”，工作台会把图片保存到根目录 `images/`，并自动填写相对路径。

支持 JPEG、PNG、WebP 和 GIF，单张图片最多 10 MB。上传图片后，仍需在“版权”板块补充作者、许可证与原始来源；相册条目通过 `creditId` 关联版权记录。

## 注意事项

- 不要把 `studio/server.py` 部署到公开服务器。
- 正式内容尽量保留原始出处、访问日期和图片许可。
- 如果直接双击 `studio/index.html`，浏览器无法保存文件；必须通过本地服务打开。
- 发布后的 `data.js` 与 `credits.js` 是生成文件。日常内容编辑应在工作台完成。
