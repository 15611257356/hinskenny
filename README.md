# 相敬如斌 · HinsKenny

一个以张敬轩（Hins Cheung）与关智斌（Kenny Kwan）为主题的非官方粉丝专题站。

[繁體中文（香港）說明](README.zh-Hant.md)

本站以时间线、舞台片段、相册与公开报道为线索，整理两人长期友谊中值得回看的片段，帮助新访客快速了解相关作品、公开互动与粉丝文化。

> “相敬如斌”是粉丝社群的称呼与解读，不代表两位当事人曾公开确认恋爱关系。本站仅整理公开资料与粉丝视角内容，尊重当事人隐私与边界。

## 站点内容

- **开场与背景音乐**：以《只是太爱你》及相关版本作为进入站点后的沉浸式体验。
- **人物介绍**：张敬轩与关智斌的基础信息和人物照片。
- **故事时间线**：从早年相识到近年公开互动的精选节点，并尽可能附上公开出处。
- **糖点合集**：精选 Bilibili 视频片段，点击封面后在页面内播放。
- **相册**：使用授权图片，支持点击放大并查看署名和许可信息。
- **出处与说明**：公开报道、视频来源及图片版权信息。

## 项目结构

```text
.
├── index.html          # 页面结构与各内容区块
├── styles.css          # 视觉主题、响应式布局、动画和组件样式
├── app.js              # 内容渲染、视频播放器和图片灯箱交互
├── data.js             # 人物、时间线、视频、相册、音乐和来源数据
├── music.js            # 背景音乐播放器
├── effects.js          # 樱花与金色闪光 Canvas 动效
├── credits.js          # 本地图片的作者、许可与 Wikimedia 来源
├── images/             # 本地图片资产
└── .gitignore          # Git 忽略规则
```

## 技术栈

- **HTML5**：语义化页面结构和原生浏览器能力。
- **CSS3**：自定义设计令牌、Grid 布局、响应式断点、过渡动画和暗色内容区。
- **原生 JavaScript**：不依赖前端框架；使用 DOM API 将 `data.js` 中的内容渲染到页面。
- **Canvas API**：绘制非阻塞的樱花和闪光背景效果。
- **Bilibili / YouTube 嵌入播放器**：承载视频和背景音乐；媒体版权归原平台及上传者所有。
- **Google Fonts**：使用 Noto Serif SC 与 Noto Sans SC 字体。
- **Wikimedia Commons 授权图片**：图片作者、许可和来源集中记录在 `credits.js`。
- **Git 与 GitHub**：进行版本管理和远端协作。

项目是纯静态站点，目前不需要 Node.js、数据库或构建工具。

## 本地预览

由于没有构建步骤，可以使用任意静态文件服务器在项目根目录预览。例如，已安装 Python 3 时：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。

直接双击 `index.html` 也可以查看基础页面；不过使用本地服务器更接近正式部署环境。

## 内容维护

大部分内容只需编辑 `data.js`：

- 新增或调整人物：修改 `people`。
- 新增时间线：在 `timeline` 数组添加条目。
- 新增视频糖点：在 `sugars` 数组添加条目；视频请使用 Bilibili BV 号。
- 新增相册图片：先确认图片可用授权，再将图片放入 `images/`，同时添加到 `photos` 和 `credits.js`。
- 更新背景音乐：修改 `music` 数组。

新增内容时请尽可能保留：事件日期、原始出处、出处访问日期、作者/上传者信息与图片许可。对于粉丝视角的解读，请和可验证的公开事实清晰区分。

## 素材、版权与社区边界

- 本地图片仅应使用自有素材、明确授权素材或符合许可要求的公开资源。
- 每张本地图片应在 `credits.js` 中记录作者、许可和原始链接。
- 外部视频、音乐和封面仍受相应平台及权利人的规则约束；若内容失效，请保留原始链接并及时替换或下线。
- 不收录私生活窥探、未证实爆料、人肉信息或攻击性内容。
- 如需下架、勘误或补充来源，请通过项目维护者公开的联系渠道反馈。

## 发展方向

当前版本聚焦轻量、沉浸式的阅读体验。后续计划的核心方向包括：

1. 部署、SEO、性能和无障碍基础建设。
2. 将内容发展为可检索、可校勘的结构化档案。
3. 建立有审核机制的投稿、翻译与社区共建流程。
4. 逐步支持多语言与全球粉丝访问。

## 贡献

欢迎贡献可靠的公开来源、授权素材、勘误、翻译和前端改进。提交前请确认：

1. 内容尊重当事人边界，并清晰区分事实、报道和粉丝解读。
2. 图片、视频和文字引用具备可说明的来源或授权。
3. 修改在桌面端和移动端均能正常浏览。
4. 不引入不必要的大型资源或第三方依赖。
