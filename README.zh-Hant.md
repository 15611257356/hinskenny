# 相敬如斌 · HinsKenny

一個以張敬軒（Hins Cheung）與關智斌（Kenny Kwan）為主題的非官方歌迷網站。

網站透過時間線、舞台片段、相簿與公開報道，整理二人多年來值得重溫的互動與作品脈絡，讓初次認識 HinsKenny 的朋友可以由淺入深地了解這段友誼與相關歌迷文化。

> 「相敬如斌」是歌迷社群的稱呼與詮釋，並不代表兩位當事人曾公開確認戀愛關係。本站只整理公開資料及歌迷角度的內容，尊重當事人的私隱與界線。

## 網站內容

- **開場與背景音樂**：以《只是太愛你》及相關版本，營造進入網站時的沉浸感。
- **人物簡介**：介紹張敬軒與關智斌的基本資料與人物相片。
- **故事時間線**：精選由早年相識至近年公開互動的重要片段，並盡可能附上公開資料來源。
- **精選片段**：收錄 Bilibili 影片，按封面即可在網頁內播放。
- **相簿**：展示已獲適當授權的相片；按圖可放大，亦可查看攝影者與授權資訊。
- **資料來源與說明**：列出公開報道、影片來源與相片版權資料。

## 項目結構

```text
.
├── index.html          # 網頁結構與各內容區塊
├── styles.css          # 視覺主題、響應式版面、動畫與元件樣式
├── app.js              # 內容渲染、影片播放器及相片燈箱互動
├── data.js             # 人物、時間線、影片、相簿、音樂與資料來源
├── music.js            # 背景音樂播放器
├── effects.js          # 櫻花與金色閃光 Canvas 動畫
├── credits.js          # 本地相片的作者、授權與 Wikimedia 來源
├── images/             # 本地相片素材
└── .gitignore          # Git 忽略規則
```

## 技術棧

- **HTML5**：語意化網頁結構與瀏覽器原生功能。
- **CSS3**：自訂設計變數、Grid 版面、響應式斷點、過場動畫與深色內容區。
- **原生 JavaScript**：不依賴前端框架；以 DOM API 把 `data.js` 的內容輸出到網頁。
- **Canvas API**：繪製不阻礙點擊操作的櫻花與閃光背景效果。
- **Bilibili / YouTube 嵌入播放器**：承載影片與背景音樂；版權歸相關平台、上載者及權利人所有。
- **Google Fonts**：使用 Noto Serif SC 與 Noto Sans SC 字體。
- **Wikimedia Commons 授權相片**：相片作者、授權條款與原始連結集中記錄於 `credits.js`。
- **Git 與 GitHub**：用於版本管理及遠端協作。

這是一個純靜態網站，目前毋須 Node.js、資料庫或建置工具。

## 本機預覽

本項目沒有建置步驟，可使用任何靜態檔案伺服器，在項目根目錄預覽。例如已安裝 Python 3 的話：

```bash
python3 -m http.server 8000
```

然後以瀏覽器開啟 `http://localhost:8000`。

直接開啟 `index.html` 亦可查看基本頁面；不過使用本機伺服器會更接近正式網站的運作方式。

## 維護內容

大部分內容都在 `data.js` 維護：

- 新增或修改人物：更新 `people`。
- 補充時間線：在 `timeline` 陣列新增項目。
- 新增精選影片：在 `sugars` 陣列新增項目；影片請填寫 Bilibili 的 BV 號。
- 新增相簿相片：先確認使用權，再把檔案放入 `images/`，同時更新 `photos` 及 `credits.js`。
- 更新背景音樂：修改 `music` 陣列。

新增內容時，請盡量保留事件日期、原始資料來源、查閱日期、作者或上載者資料，以及相片授權條款。歌迷詮釋應與可核實的公開事實清楚分開。

## 素材、版權與社群界線

- 本地相片只應使用自行拍攝、已獲清楚授權，或符合授權條款的公開素材。
- 每張本地相片均應在 `credits.js` 記錄作者、授權與原始連結。
- 外部影片、音樂和封面仍受所屬平台與權利人的規則約束；若內容失效，請保留原始連結，並及時替換或下架。
- 不收錄窺探私人生活、未經證實的傳聞、起底資料或具攻擊性的內容。
- 如需要下架內容、提出更正或補充資料來源，請透過項目維護者公開的聯絡方法提出。

## 發展方向

現時版本以輕量、具沉浸感的閱讀體驗為主。往後的優先工作包括：

1. 建立部署、SEO、效能與無障礙基礎。
2. 將內容整理成可搜尋、可校對的結構化資料庫。
3. 建立設有審核流程的投稿、翻譯及社群共建機制。
4. 逐步支援多語言與全球歌迷使用。
